# 読み上げの音声（VOICEVOX:四国めたん）

指し手・残り時間・終局の読み上げに使う音声です。VOICEVOX（https://voicevox.hiroshiba.jp/）の四国めたん（ノーマル）で前もって作りました。

- pack.bin … MP3（24kHz、モノラル、32kbps）を並べたもの
- index.json … キー → [開始バイト, 長さ]
- 作り方 … tools/build_voice.py

キーの形
- `76|G||` 座標＋駒＋成・不成・打（`76|S||成`、`55|B||打` など）。`do|R||` は同
- `suf|右|`、`suf|左上|成` … 右・左・上・引・寄・直の言葉（駒までの音のあとにつなぐ）
- `side|0`（せんて）、`side|1`（ごて）
- `clk|600` … 残り時間（10分〜1秒）
- `end|詰み`、`made|85`（まで85手で）、`tail|先手の勝ち`

アクセント: 座標は4モーラの1語で3モーラ目のあとで下がる（ななは↘ち）。駒の名前は平板。

利用規約: 四国めたん音源利用規約（https://zunko.jp/con_ongen_kiyaku.html）と VOICEVOX の利用規約に従います。クレジットは「VOICEVOX:四国めたん」。この音声はこのアプリの読み上げのためのもので、ほかの用途に使う場合はそれぞれの規約を確かめてください。
