# 詰将棋集（tsume.txt）

やねうら王の作者 やねうらお 氏が2020年12月25日に公開した「詰将棋500万問」から、3手・5手・7手・9手・11手詰めをそれぞれ1500問ずつ、ランダムに選んだものです。

- 配布ページ: https://yaneuraou.yaneu.com/2020/12/25/christmas-present/
- 利用条件: 作者は著作権を主張せず、自由に使ってよいとしています（「著作権は主張しませんのでご自由にお使いください。」）
- 選び方: tools/build_tsume.mjs（攻め方の手番で、王手をかける手がある局面だけを残す）
- 形式: 1行に1問。「手数<TAB>局面のSFEN」
