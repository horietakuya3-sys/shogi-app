# 将棋研究

スマホのブラウザ（Android Chrome）で動く将棋の研究用アプリです。インストール不要のPWAで、ホーム画面に追加して使えます。

## できること（現在）

- 複数の候補手と、それぞれの評価値・読み筋を表示（候補数は1〜5で切り替え）
- 最善手を盤上に矢印で表示
- KIF / KI2 / SFEN の棋譜を読み込み（ファイル選択、貼り付け、他アプリからの共有）
- 盤上で自由に指して変化を検討し、ワンタップで本譜に戻る
- KIF形式で保存・コピー
- 最後に見ていた棋譜と局面を自動で保存

## これから作るもの

対局レビュー（悪手の指摘と評価値グラフ）、成績表と弱点の指摘、レベル調整付きの対局、復習問題、戦法指定。詳しい仕様は開発用のメモにまとめています。

## 仕組み

- 思考エンジン: [やねうら王](https://github.com/yaneurao/YaneuraOu) のWebAssembly版 [@mizarjp/yaneuraou.k-p](https://www.npmjs.com/package/@mizarjp/yaneuraou.k-p)（評価関数 水匠Petite 内蔵）
- エンジンは端末の中で動くため、解析に通信は使いません
- エンジンに必要な SharedArrayBuffer を GitHub Pages で使うため、Service Worker（`sw.js`）で COOP/COEP ヘッダーを付け直しています。初回だけページが自動で1回読み込み直されます
