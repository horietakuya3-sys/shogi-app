利用規約

第1版 2026年11月19日

この規約は、将棋研究（以下「本アプリ」）を使うときの約束ごとです。本アプリを使い始めた時点で、この規約に同意したものとします。

第1条 本アプリについて

本アプリは、作成者が個人で作り、無料で公開している将棋の研究用アプリです。営利を目的としたサービスではありません。作成者は GitHub アカウント horietakuya3-sys の持ち主です。

第2条 料金

本アプリは無料で使えます。アプリ内で課金や広告はありません。通信料は利用者の負担になります。

第3条 データの取り扱い

  1. 本アプリは、利用者の個人情報を集めません。アカウント登録もありません。
  2. 対局の記録、局後解析の結果、復習の問題、設定は、利用者の端末のブラウザの中にだけ保存されます。作成者を含め、ほかの誰かに送られることはありません。
  3. 将棋エンジンは端末の中で動きます。指し手や局面を外部のサーバーへ送って解析することはありません。
  4. 本アプリは GitHub Pages で配信しています。ページを開くときの通信について、GitHub がアクセス記録（IPアドレスなど）を扱う場合があります。その扱いは GitHub のプライバシーに関する規定によります。
  5. 保存したデータは、ブラウザのデータ消去や端末の容量不足などで消えることがあります。大切な記録は、プロフィール画面の「記録を書き出す」で控えを取っておいてください。

第4条 守ってほしいこと

  1. 将棋ウォーズ、将棋倶楽部24、lishogi などのオンライン対局や、大会・公式戦の対局中に、本アプリで指し手を調べないでください。多くの対局サービスや大会は、ソフトの助けを借りて指すことを禁止しています。
  2. 本アプリや配信元のサーバーに過剰な負荷をかけたり、動作を妨げたりしないでください。
  3. 法令や公序良俗に反する使い方をしないでください。

第5条 保証しないこと

  1. 本アプリは、いまある状態のままで提供します。将棋エンジンの評価値、候補手、悪手の判定、戦法の判定などの内容が正しいこと、目的に合うこと、すべての端末で動くことは保証しません。
  2. 本アプリを使ったこと、または使えなかったことで利用者に生じた損害（データが消えた場合を含みます）について、作成者は、作成者に故意または重大な過失がある場合を除き、責任を負いません。

第6条 変更と終了

作成者は、予告なく本アプリの内容を変えたり、公開をやめたりすることがあります。規約を変えたときは、このページで知らせます。変更後に本アプリを使った場合は、新しい規約に同意したものとします。

第7条 問い合わせ

不具合や質問は、本アプリを紹介した作成者に直接伝えるか、GitHub の Issues に書き込んでください。
